# Custom Icons

Place custom icon assets here:

- `app_icon.svg` — Main app icon source (use to generate all platform sizes)
- `notification_icon.png` — Notification icon (Android: transparent, 96×96)
- Icon set files if using a custom icon family (not Material Symbols)

## Platform Icons (generated from 1024×1024 source)

These are stored platform-specifically:

- **Android:** `android/app/src/main/res/mipmap-*/ic_launcher.png`
- **iOS:** `ios/Runner/Assets.xcassets/AppIcon.appiconset/`
- **Web:** `web/icons/Icon-*.png`
- **Favicon:** `web/favicon.png`
