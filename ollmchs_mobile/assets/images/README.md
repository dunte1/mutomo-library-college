Place these image assets here:

- `logo_primary.png` / `logo_primary.svg` — Main OLLMCHS Library logo
- `logo_light.png` / `logo_light.svg` — Logo for light backgrounds
- `logo_dark.png` / `logo_dark.svg` — Logo for dark backgrounds
- `logo_icon.png` / `logo_icon.svg` — Icon-only version
- `logo_horizontal.png` / `logo_horizontal.svg` — Horizontal layout
- `logo_vertical.png` / `logo_vertical.svg` — Vertical layout
- `logo_monochrome.png` / `logo_monochrome.svg` — Monochrome version
