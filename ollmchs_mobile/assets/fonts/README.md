# Custom Fonts

Place custom font files (.ttf, .otf) here if not using Google Fonts.

Currently using Google Fonts (Inter + Poppins) via the `google_fonts` package — no local font files needed unless offline support is required.

To add local fonts:
1. Place .ttf/.otf files here
2. Register in `pubspec.yaml` under `flutter -> fonts:`
3. Use in `app_theme.dart`
